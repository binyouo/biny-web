# Biny 官网

产品首页、下载页与中文使用文档。基于 Vite、React 和 Tailwind CSS，构建结果是静态文件。

## 本地开发

需要 Node.js 22.12 或更新版本，以及 pnpm 10.6.5。客户端演示直接引用根目录的渲染器源码，先在 Biny 根目录安装依赖，再安装官网包：

```bash
pnpm install --frozen-lockfile
cd website
pnpm install --ignore-workspace --frozen-lockfile
pnpm dev
```

开发地址默认为 `http://localhost:5173/zh`。验证和预览：

```bash
pnpm test
pnpm typecheck
pnpm build
pnpm preview
```

网站源码由根仓库的 `.gitignore` 忽略，属于当前本地工作区；这些修改不会自动进入 Git 提交。

## 页面与职责

| 路径 | 内容 |
| --- | --- |
| `/zh` | 产品介绍、预置交互演示、功能展示、模型服务商与常见问题 |
| `/zh/download` | 实时桌面发布信息、npm 安装与源码启动 |
| `/zh/docs` | 中文文档概览 |
| `/zh/docs/<slug>` | 安装、快速开始、会话、Provider、记忆、工具、扩展与任务指南 |
| `/client-demo.html` | 独立的客户端预置演示，由首页 iframe 加载 |

`/` 转到 `/zh`；`/docs` 和 `/docs/<slug>` 转到对应中文文档路径，保留查询参数与锚点。未知文档展示明确的 404 内容。

```text
src/
  App.tsx                 路由、按页加载、滚动与站点布局
  components/             导航、页脚、代码复制与基础图标
  pages/                  首页、下载、文档与 404 页面
  sections/               首页各区块和 home.css
  docs/content.ts         分组文章、章节与内容
  docs/search.ts          文档搜索与标题排序
  docs/docs.css           文档布局和响应式样式
  demo/                   独立客户端视图、播放器与 iframe 消息桥接
  i18n/zh.ts              首页和演示中文文案
  lib/site.ts             项目仓库、Releases 与 npm 链接
  lib/releases.ts         发布结果解析与请求状态
  styles.css              全站主题、导航、下载与共用组件样式
tests/                    文档搜索、路径、下载目录与演示桥接回归测试
```

## 内容维护

文档按用户操作编写，发布前核对当前 Biny 的源码、命令帮助与设置入口。官网不直接发布本地 `docs/specs/` 中的内部实现笔记。

- 项目链接统一来自 `src/lib/site.ts`，不在页面中保存版本号。
- 产品演示使用预置场景，访客操作只改变演示状态，不连接模型、不读写真实项目。
- 首页的功能示意不冒充产品截图；修改能力描述时同时检查演示文案与对应指南。
- 文档搜索覆盖标题、关键词、描述与正文；多词查询要求每个词都匹配同一篇文章。
- 新增文章时为页面和章节设置唯一标识，并同步 `public/sitemap.xml`。
- npm 安装包与当前源码可能处于不同版本，文档命令仍应按所使用版本的帮助核对。

## 视觉样式

官网浅色主题采用暖白页面、炭黑文字与主按钮，低饱和蓝用于链接、焦点与批准操作；深色主题使用暖炭灰底色。首页、文档与下载共用 `src/styles.css` 中的颜色令牌。

官网标题与正文共用无衬线字体，代码使用系统等宽字体。卡片、背景与浮层通过底色、细边框和统一阴影区分，调整颜色时同时检查正文、辅助文字、选中态和按钮文字的对比度。

### 客户端演示

`client-demo.html` 有独立的 React 入口和样式上下文，直接加载 `src/desktop/renderer/src/styles/layers.css` 与 `crystal.css`，复用客户端图标、折叠、侧栏悬停、代码视图、文件卡和复制按钮。布局沿用客户端类名，官网主题不会覆盖其内部样式。

当前预置外观对应深色默认主题、系统字体 18、紧凑密度、侧栏宽度 254px。内嵌视窗固定为 1311×847，窄页面整体等比缩小，放大查看也保持相同比例；直接打开独立入口时使用浏览器的实际视窗。

会话切换、侧栏与活动折叠、工具详情、权限允许/拒绝、复制、重播和跳过可操作。搜索、设置、工具栏面板、模型菜单、输入和文件打开只保留外观，不调用桌面 IPC，也不运行模型或本地文件操作。脚本使用预置消息、耗时、时间和上下文用量。

iframe 通信同时检查窗口身份、origin 和明确的消息类型；加载超时提供重试。部署时需要同时保留 `index.html`、`client-demo.html` 与生成的静态资源，客户端演示入口不能被 SPA 回退规则替换。

## 下载状态

下载页请求 npm 最新版本与 GitHub 最新 Release，两者独立加载，请求上限为 10 秒。页面切换会取消未完成请求；桌面版本获取失败时提供重试和发布记录入口。

| 结果 | 页面表现 |
| --- | --- |
| 最新 Release 包含可识别的 macOS 安装包 | 列出明确标注 arm64、x64 或 universal 的 DMG/ZIP |
| 404 或最新 Release 没有对应安装包 | 说明暂未找到安装包，提供发布记录和源码入口 |
| 请求失败、超时或返回无效内容 | 显示获取失败并提供重试 |

未标注架构的包不猜测为 Intel，其他系统的 ZIP 不进入 macOS 下载目录。签名、公证与实际可用版本以各次发布说明为准。

## 部署与验收

`pnpm build` 输出到 `dist/`。SPA 深路径需返回 `index.html`，`vercel.json` 和 `public/_redirects` 已提供相应规则。`vite.config.ts` 是唯一构建配置来源。

人工检查首页演示、导航、主题、文档搜索、目录锚点与上下篇；在窄屏检查移动菜单和文档目录；在下载页检查失败重试和代码复制反馈。演示放大后对照客户端检查侧栏、工具栏、正文、文件卡、输入框和悬停；切换会话，展开工具活动，允许或拒绝权限，再重播；用 Tab 和 Escape 检查展开窗口的焦点和退出。测试、类型检查与构建通过不表示界面已验收。
